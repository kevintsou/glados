# BC-009 — register 版本辨識與差異查詢工具

## 現況

P0 草擬程式碼建立設定時，要決定新 IC 每個 register block 用哪一版、哪些沿用前代（[glados/impl/recipe.md](../../../impl/recipe.md) 的 `register_blocks`）。目前沒有工具能回答兩個問題：

- 起點 code 用的是外部來源的哪一版？
- 兩版之間差在哪裡？

E39 待決事項第 13 項就卡在這裡（[glados/projects/E39.md](../../../projects/E39.md) E7）：PS5039 缺 apu、bmu、cop1、d2h、dmac、mctp、nvme、pcie、semaphore、wbe、other 這些 block，而且同一個 block 有多個版本以及 `_new`、`_r8r16`、`_fw` 等變體。BC-008 的 E39 試跑沒有工具可用，只能自己挑最新版，所以只算試跑（BC-008 接續紀錄）。

register 分享資料夾 `\\192.168.197.61\RegSpecTranslator\<IC>\<block>\<IC>_<BLOCK>_v<版本>[_變體]\` 裡，每個版本有 translator 產生的 `.h`，以及 RegSpec xml（`<regs_list>`、`<regs>`、`<register>`、`<bitfield>`，屬性包括位址、bit 位置、存取類型與 reset 值）。header 裡有不影響內容的標記，例如 `version: x.y.z`、`time:...`；起點的 header 另有 `EXCEL_VERSION`、`FPGA_IP_VERSION`、`TOOL_VERSION`、`HEADER_VERSION`、`script version` 等行。

## 本項範圍

在 bct_knowledge_base 的 `tools/` 下新增一個獨立工具，不放在 bcgen 裡：bcgen 只用在 P1，這個工具給 P0 的討論和 bct-p0 用，之後串接層也可以用它。工具只讀明確傳入的輸入。framework/08 §8.2 第 13 項的 HW spec 查詢與 svn 快照不在本項。

認領後補上實際 owned_paths、branch/worktree；先讀目標 repo 的 AGENTS.md 與最新 diff，不覆蓋其他 agent 的工作。

## 完成條件

- [ ] 輸入都由參數明確傳入：起點目錄（固定 commit 的匯出）、register 快照目錄（資料夾快照，含 `.h` 與 RegSpec xml），以及 block 與 code 目錄的對照。不讀分享資料夾的原始位置、全域設定或環境變數。
- [ ] **版本辨識**：
  - 排除只代表工具或產生時間的行，排除規則寫在程式與文件裡，報告列出實際排除了哪些行。
  - 逐個 block 判定起點用的是快照的哪個版本與變體，結果分成「完全相同」「最接近（附差異摘要）」「找不到」。
  - `FPGA_IP_VERSION` 這類代表內容版本的標記不能排除，要當成辨識依據列出。
- [ ] **結構化差異**：
  - 同一個 block 兩個版本之間，列出 register 與欄位的新增、刪除、位址、bit 位置與寬度、存取類型、reset 值的變動。
  - 以 RegSpec xml 為主；沒有 xml 時解析 header，並在報告標明依據是什麼。
  - 只是名稱大小寫或前綴不同的，不能誤判成刪除再新增。
- [ ] **快照**：計算資料夾快照的 `snapshot_sha256`，算法照 [glados/impl/recipe.md](../../../impl/recipe.md)「格式狀態」，和 bcgen 衍生模式的結果一致。
- [ ] **輸出**：JSON（附格式說明）與給人看的 Markdown。同樣的輸入重跑，輸出逐 byte 相同（不含時間或本機路徑）。
- [ ] **E39 實跑一次**：
  - 用起點 `83dc1a65b` 的 `ws_fw/src_root/proj/ps5037/lib/dal/inc/` 對 PS5037 快照辨識版本。
  - 對每個 block，列出 PS5037 採用的版本和 PS5039 各版本的差異。
  - 列出 PS5039 缺少的 block。
  - 報告標明「供 P0 討論，不是 P0 定案」，放在 repo 以外。
- [ ] 只用 Python 標準函式庫，測試涵蓋：排除規則、辨識的三種結果、xml 與 header 兩種差異來源、名稱正規化、輸出可重現、快照 hash 和 bcgen 一致。
