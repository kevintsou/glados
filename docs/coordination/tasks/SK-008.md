# SK-008 — M4 實作 skill

## 現況

GLADOS v0.10（2026-10-20）起，串接層不派工給 AI：AI 的工作一律由人開 agent 照 skill 完成，串接層只開工與收件（[glados/framework/04_rules.md](../../../framework/04_rules.md) §4.2）。M4 的規劃與實作原本由串接層派工給 AI，現在改由人開 agent 照本 skill 做；正式 build 仍由串接層執行。

## 本項範圍

在 bct_knowledge_base 的 `Skills/` 新增 M4 的實作 skill。用法和 bct-p0 一樣：人在工作區開 agent，叫它讀工作包、照本 skill 做。輸入是模組 spec、驗收合約、M2 的測試、差異分析與架構的模組段、上一輪的交接說明；產出是模組 code 範圍內的修改、`artifacts/modules/<模組>/plan.md` 與交接說明。

每個做 AI 工作的 skill 都要守 [glados/impl/ai_node_execution.md](../../../impl/ai_node_execution.md)「做 AI 工作的 skill 要守的規則」：先讀工作包；只寫可寫範圍；最多 3 輪（從工作包的輪數接著算，第 3 輪還沒過就停下來交給人）；寫交接說明後由 agent 或人提交；不碰簽核。

認領後補上實際 owned_paths、branch/worktree；先讀目標 repo 的 AGENTS.md 與最新 diff，不覆蓋其他 agent 的工作。
