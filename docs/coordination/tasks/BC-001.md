# BC-001 — bcgen 只讀明確傳入的輸入（不讀隱藏的全域狀態）

## 現況

bcgen 執行時會自己讀全域的 `settings.json`、共用路徑下的 catalog 與自訂功能、環境變數與快取。就算串接層準備好固定版本的快照，bcgen 仍可能讀到別的版本。

## 本項範圍

Tools/bcgen 的輸入解析與路徑檢查。**固定版本是串接層的責任**（glados framework/04 §4.2：派工前固定輸入、準備工作區）：決定用哪個版本、準備起點 worktree 與外部來源快照、計算正式 hash，都在 openBCT adapter（OBC-011）。bcgen 只負責「能被固定」：只讀傳入的東西。

認領後補上實際 owned_paths、branch/worktree；先讀目標 repo 的 AGENTS.md 與最新 diff，不覆蓋其他 agent 的工作。

## 完成條件

- [ ] 所有輸入（起點目錄、catalog、pitfalls、公版 code 包、recipe）都由參數明確傳入；不讀 `settings.json`、全域 catalog、自訂功能、環境變數或快取這類隱藏狀態。
- [ ] 只讀傳入的路徑，越界或逃逸（`..`、symlink）一律拒絕；唯讀模式完全不寫檔（不寫 settings、custom、FW）。
- [ ] 同樣的輸入得到逐位元組相同的輸出；執行時間等事件資訊另外存放，不混進內容。
- [ ] bcgen 回報自己讀到的檔案與 hash，只當成和串接層核對的參考，不是正式證據。
