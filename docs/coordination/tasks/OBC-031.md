# OBC-031 — P1 機械替換由串接層固定輸入並執行 bcgen

## 現況

原本在 OBC-011（將唯讀 bcgen CLI 接入 GLADOS adapter）裡。2026-10-19 使用者決定 bcgen 只用在 P1 的機械替換，OBC-011 的唯讀命令列部分不做（[glados/impl/bcgen.md](../../../impl/bcgen.md) B1、B4），仍需要的「固定輸入」與「P1 派工」移到本項。bcgen 已能只讀明確傳入的輸入（BC-001，bct_knowledge_base `1c97546`）；產生功能的安全性（BC-007）與以前代 code base 衍生（BC-008）還沒做。

## 本項範圍

openBCT 的 bcgen adapter：依 G0 核准版本固定輸入、在 P1 第 2 步派工執行 bcgen 產生模式、保存輸入與輸出的證據。固定版本是串接層的責任（[glados/framework/04_rules.md](../../../framework/04_rules.md) §4.2），bcgen 只負責只讀傳入的輸入。

認領後補上實際 owned_paths、branch/worktree；先讀目標 repo 的 AGENTS.md 與最新 diff，不覆蓋其他 agent 的工作。

## 完成條件

- [ ] 依 G0 核准的專案設定與環境清單決定版本：起點 commit、外部來源快照、bcgen 程式與 catalog／公版 code 包；準備 worktree 與快照，把位置明確傳給 bcgen，不讓 bcgen 自行解析。
- [ ] 串接層自己計算所有輸入與輸出的 hash 當正式證據；bcgen 回報的 hash 只用來核對，不一致就不放行。bcgen 的版本由串接層依固定的 bct_knowledge_base commit 計算，不靠 bcgen 自報。
- [ ] 機械替換只寫生成區與起始複製區、同一份輸入重跑逐檔相同，結果 commit 成獨立的 commit 並寫進基底建立紀錄（[glados/nodes/P1.md](../../../nodes/P1.md) 第 2 步）。
- [ ] AI 節點的命令允許清單不列 bcgen；機械替換只由串接層派工。
- [ ] 把 G0 核准的專案設定建立設定區塊原樣交給生成工具（格式見 [glados/impl/recipe.md](../../../impl/recipe.md)），只把來源代號換成已核對 hash 的快照目錄、用參數傳入；不另做格式轉換，也不新增 P0 產出。
