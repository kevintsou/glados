# SK-013 — P5 差異清單 skill

## 現況

GLADOS v0.11 起，`build_targets` 有標交付版本與驗證版本時，P5 要產出兩者的差異清單（[glados/framework/05_checks.md](../../../framework/05_checks.md) §5.4、[09 §9.3](../../../framework/09_build_configurations.md#93-規劃時不能忽略的事)）。openBCT 已有 `P5:variants` 這一步（`p5review.py`），但 KB 沒有教 agent 寫 `variants.md` 的 skill，工作包只寫「沒有專用 skill」。

## 本項範圍

新增 `Skills/bct-p5-variants`：人開 agent 讀 P5:variants 的工作包，照本 skill 寫 `artifacts/acceptance/variants.md` 與交接說明。表格「交付設定｜驗證設定｜差異｜說明｜驗證缺口」，每個交付設定至少一列，沒有差異也寫一列「無」並說明；每項寫說明或登記驗證缺口，登記的缺口成為 G3 的風險。沒有 `role` 時這一步不適用。寫清單的 session 不能接著做 P5 安全審查，也不審自己的清單。

## 完成條件

- [x] skill 照 openBCT 的收件規則（`VARIANTS_GUIDE`、`variants_row`）寫，離線檢查和 openBCT 的判定一致。
- [ ] 受測 agent 的行為評估（with／without skill）。
- [x] 使用者確認後併入 KB main（`87ec516a`）。
