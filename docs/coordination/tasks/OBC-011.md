# OBC-011 — 將唯讀 bcgen CLI 接入 GLADOS adapter

## 現況

通用 external tools 已有；bcgen 固定輸入、欄位映射及 checker 尚未對接。固定輸入是串接層的責任（framework/04 §4.2），bcgen 只負責只讀傳入的輸入（BC-001）。

## 本項範圍

bcgen tool adapter/輸出保存/獨立 checker；不重寫 parser。包括依核准版本固定 bcgen 的全部輸入，以及 P1 機械替換時由串接層執行 bcgen 的派工。

認領後補上實際 owned_paths、branch/worktree；先讀目標 repo 的 AGENTS.md 與最新 diff，不覆蓋其他 agent 的工作。

## 完成條件

- [ ] 依 G0 核准的專案設定與環境清單決定版本：起點 commit、外部來源快照、bcgen 程式與 catalog／pitfalls／公版 code 包；準備 worktree 與快照，把位置明確傳給 bcgen，不讓 bcgen 自行解析。
- [ ] 串接層自己計算所有輸入與輸出的 hash 當正式證據；bcgen 回報的 hash 只用來核對，不一致就不放行。
- [ ] 映射 profile_draft，保存來源與觀察程度。
- [ ] AI 查詢與服務獨立 CLI checker 分開記錄，服務計算正式 hash。
- [ ] AI 用的 CLI／MCP 白名單禁止 generate/HAL apply/auto-import/custom/settings 寫入。P1 的機械替換由串接層依生成配方執行 bcgen，只寫生成區、重跑結果相同，不開放給 AI 呼叫。
