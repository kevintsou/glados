## 現況

2026-10-19 使用者決定：P0 由 AI 直接查固定的 source／spec／限定 KB，不經 bcgen；bcgen 只用在 P1 的機械替換（[glados/impl/bcgen.md](../../../impl/bcgen.md) B1、B4）。bcgen 唯讀命令列不做，本項的 AI 命令允許清單、`profile_draft` 映射與 AI 查詢紀錄都不需要。本項沒有任何實作；status 標 done 只代表「已決定不做、不需再處理」。

決定前的現況：通用 external tools 已有；bcgen 固定輸入、欄位映射及 checker 尚未對接。固定輸入是串接層的責任（framework/04 §4.2），bcgen 只負責只讀傳入的輸入（BC-001）。

## 本項範圍

bcgen tool adapter/輸出保存/獨立 checker；不重寫 parser。包括依核准版本固定 bcgen 的全部輸入，以及 P1 機械替換時由串接層執行 bcgen 的派工。

認領後補上實際 owned_paths、branch/worktree；先讀目標 repo 的 AGENTS.md 與最新 diff，不覆蓋其他 agent 的工作。
