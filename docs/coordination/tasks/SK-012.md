# SK-012 — P5 安全審查 skill

## 現況

GLADOS v0.10（2026-10-20）起，串接層不派工給 AI：AI 的工作一律由人開 agent 照 skill 完成，串接層只開工與收件（[glados/framework/04_rules.md](../../../framework/04_rules.md) §4.2）。P5 的安全審查原本由串接層派工給 AI，現在改由人另開一次開工、照本 skill 審查；全量驗收的執行仍由串接層負責。

## 本項範圍

在 bct_knowledge_base 的 `Skills/` 新增 P5 的安全審查 skill。用法和 bct-p0 一樣：人在工作區開 agent，叫它讀工作包、照本 skill 做。輸入是整合 branch 的 diff 與 boot flow、專案的必要規則與安全相關的 spec 條目；產出是 `artifacts/acceptance/` 的安全審查報告與交接說明，不改 code。

每個做 AI 工作的 skill 都要守 [glados/impl/ai_node_execution.md](../../../impl/ai_node_execution.md)「做 AI 工作的 skill 要守的規則」：先讀工作包；只寫可寫範圍；寫交接說明後由 agent 或人提交；不碰簽核。

認領後補上實際 owned_paths、branch/worktree；先讀目標 repo 的 AGENTS.md 與最新 diff，不覆蓋其他 agent 的工作。
