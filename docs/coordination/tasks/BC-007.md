## 現況

生成 build script 可能被 tee 吞 make 失敗；generate 清空輸出。v0.8.5 起 P1 依生成配方用 bcgen 做機械替換，E39 就要用到，不再是流程外的條件式 backlog。

## 本項範圍

generation/buildgen 安全與 provenance。以前代 code base 衍生與 ARM 支援另見 BC-008。

認領後補上實際 owned_paths、branch/worktree；先讀目標 repo 的 AGENTS.md 與最新 diff，不覆蓋其他 agent 的工作。

## 完成條件

- [ ] make 失敗而 tee 成功仍返回失敗，有回歸案例。
- [ ] 先寫到暫存區，完成後才發布；只寫生成區，不清空生成區以外的檔案；拒絕覆蓋已凍結的輸出。
- [ ] 輸出逐檔清單（manifest）；同一份生成配方、工具版本與輸入重跑，產出逐檔相同（對應 framework/05「機械替換可重現」）。
- [ ] stub、缺檔不能只是 warning：要能區分「只能當設定檔看」和「可以建立基線」，P1 用嚴格模式。
