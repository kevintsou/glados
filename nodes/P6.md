# P6 交付

## 介面（框架固定）

- **目的**：交出最終版本。mask ROM 專案的交付就是 tapeout，交付後不能回頭。
- **層級**：專案
- **從哪裡進來**：P5 完成，而且 G3 已核准。
- **輸入**：全量驗收報告（已通過且有效）、G3 核准（對應目前整合 branch 的 commit 與 image hash）。
- **輸出**：release 包（含 hash，放在專案設定的交付位置）、交付紀錄。
- **出口檢查**：交付內容與核准版本相符、必要核准齊全。
- **出口關卡**：無。G3 在進入 P6 之前核准，因為交付後不能回頭（待確認：[framework/08 框架第 2 項](../framework/08_open_questions.md#81-框架待決)）。
- **失敗退回**：release 包和核准的版本不符 → 退回 P5。
- **迴圈上限**：不適用。
- **可寫範圍**：專案設定的交付位置。
- **人怎麼參與**：由人執行。
- **獨立性要求**：無。

**不可逆動作**：交付列在專案設定的「不可逆動作清單」，只能在 G3 核准有效時執行。
