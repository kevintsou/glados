# M6 獨立審查

## 介面（框架固定）

- **目的**：由獨立的審查者確認 diff 沒有功能錯誤、安全問題、記憶體越界、介面違約或違反必要規則。
- **層級**：模組
- **從哪裡進來**：M5 PASS。
- **輸入**：模組 commit（SHA 與 diff hash）、實作計畫、模組 spec、架構文件、M5 驗證報告。
- **輸出**：審查報告與發現紀錄（`artifacts/modules/<模組>/review/`）；發現紀錄每一項一筆，格式見 [framework/03 §3.9](../framework/03_artifacts.md#39-審查發現紀錄)。
- **出口檢查**：code 審查、審查沒有未處置的阻擋項目、審查者與執行者不同。
- **出口關卡**：無。
- **失敗退回**：需要修正 → 交給 R 失敗分類（code 錯回 M4；需求或架構爭議回對應的關卡）。
- **迴圈上限**：不適用（要修正的交給 R，輪數記在被退回的那一站）。
- **可寫範圍**：可寫 `artifacts/modules/<模組>/review/`；禁止改 FW source 與測試。
- **人怎麼參與**：不參與。
- **獨立性要求**：審查者和 M4 的實作者不同（另一個 session，最好換模型）。

放行規則見 [framework/04 §4.8](../framework/04_rules.md#48-審查放行)。審查結果綁定被審的 diff hash；diff 一改，審查證據就過期。
