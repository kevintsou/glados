# P2 差異分析

## 介面（框架固定）

- **目的**：把範圍 CR 對到 code 位置，再切成模組。
- **層級**：專案
- **從哪裡進來**：
  - P1 完成之後。
  - C 變更分析判定「全新功能，不碰既有模組」→ 在 P2 追加模組。
- **輸入**：
  - project.md（範圍 CR 清單快照）。
  - 基線報告。
  - 專案設定的 code 模組對照、共用層規則、衝突熱點。
- **輸出**：差異分析（`delta.md`），內容包括：
  - 每張範圍 CR 對到哪些 code、屬於哪個模組，或明列「這版不做」並附理由。
  - 模組切分：每個模組的 code 範圍。
  - 受影響的既有功能（regression 範圍）。
  - 模組之間的相依與執行順序；改到衝突熱點檔案的模組標為序列。
- **出口檢查**：範圍 CR 都有歸屬、模組順序已定、regression 範圍已定。
- **出口關卡**：G1 範圍核准。
- **失敗退回**：資訊不足 → P0。
- **迴圈上限**：待定。
- **可寫範圍**：可寫 `artifacts/delta.md`；禁止改 FW source。
- **人怎麼參與**：只在關卡。
- **獨立性要求**：無。
