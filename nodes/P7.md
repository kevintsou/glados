# P7 回寫

## 介面（框架固定）

- **目的**：把這次的錯變成下次的能力。
- **層級**：專案
- **由誰做**：外部互動。
- **從哪裡進來**：P6 完成之後；也可以在專案進行中隨時做。
- **輸入**：整個專案的紀錄，包括交給人的決定、審查發現、各節點重做的輪數、驗證缺口、變更紀錄。
- **輸出**：回寫提案（`artifacts/writeback/`）：知識庫、規則、skill、hook 各一份清單，每一項附上來源紀錄；以及知識庫評測結果。
- **擋關檢查**：無。知識庫評測照跑，退步時在提案裡註明，但不擋任何東西。
- **收件檢查**：見 [framework/05 §5.5](../framework/05_checks.md#55-收件檢查) 的 P7 列。
- **出口關卡**：無。回寫提案由人有空時處理；實際修改依各自 repo 的流程提交。
- **可寫範圍**：可寫 `artifacts/writeback/`。知識庫與 skill 的實際修改，依各自 repo 的流程提交（例如用 vault-smith 提交到 bct_knowledge_base），不直接改 FW repo。

## 實作（待展開）

- **執行者**：人＋agent。
- **工具**：vault-smith（寫知識庫）、the-validator（驗知識庫沒退步）、skill-creator。
