# P7 回寫

## 介面（框架固定）

- **目的**：把這次的錯變成下次的能力。
- **層級**：專案
- **從哪裡進來**：P6 完成之後。
- **輸入**：整個專案的正式紀錄，包括 R 失敗分類的統計與輪數、審查發現、交給人的紀錄、驗證缺口、變更紀錄。
- **輸出**：回寫提案（`artifacts/writeback/`）：知識庫、規則、skill、hook 各一份清單，每一項附上來源紀錄；以及知識庫評測結果。
- **出口檢查**：知識庫 eval 不退步。
- **出口關卡**：人確認回寫提案（是否算正式關卡待決：[framework/08 框架第 3 項](../framework/08_open_questions.md#81-框架待決)）。
- **失敗退回**：eval 退步 → 留在 P7 修正提案。
- **迴圈上限**：待定。
- **可寫範圍**：可寫 `artifacts/writeback/`。知識庫與 skill 的實際修改，依各自 repo 的流程提交（例如用 vault-smith 提交到 bct_knowledge_base），不直接改 FW repo。
- **人怎麼參與**：確認 AI 的回寫提案。
- **獨立性要求**：無。

## 實作（待展開）

- **執行者**：AI 提案＋人確認。
- **工具**：vault-smith（寫知識庫）、the-validator（驗知識庫沒退步）、skill-creator。
