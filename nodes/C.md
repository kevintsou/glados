# C 變更

## 介面（框架固定）

- **目的**：G1 核准後進來的需求變更，由人決定這一版接不接；接的話從哪一站重做。
- **層級**：變更（不在主流程上）
- **由誰做**：外部互動。
- **從哪裡進來**：G1 核准後，任何不在 G1 核准範圍裡的需求新增、修改或取消，包括新進的 CR、外部來源同步發現的 CR／spec 內容差異，以及有人直接在 repo 裡改了已核准的需求、介面、預算或專案設定（[framework/04 §4.6](../framework/04_rules.md#46-需求變更)）。
- **輸入**：變更 CR 或有差異的來源（新舊內容）、範圍清單、差異分析、架構文件，以及串接層的影響提示（哪些節點讀過相關的檔案）。
- **輸出**：變更決定（`artifacts/changes/<CR 編號>/`）：接或不接；接的話寫明要改哪些產出物、從哪一站重做、變更進來的時間點（模組還沒開始／正在跑／已合入整合 branch）。範圍清單要改時一起改。agent 可以附上影響建議，只供人參考。
- **擋關檢查**：無（由 GC 決定）。
- **收件檢查**：見 [framework/05 §5.5](../framework/05_checks.md#55-收件檢查) 的 C 列。
- **出口關卡**：GC 變更核准。
- **失敗時**：影響判斷不出來，就請人在 GC 決定先不接，或指定從比較上游的一站重做。
- **可寫範圍**：可寫 `artifacts/changes/<CR 編號>/`；GC 接受後可改範圍清單（只限決定列出的項目）；不能改來源快照（由工具產生）與其他節點的產出物；禁止改 FW source。

接受之後，工具產生來源快照的新版本；其他要改的產出物由人指定的那一站重做，照那一站的檢查與關卡。常見的重做起點見 [framework/04 §4.6](../framework/04_rules.md#46-需求變更)。
