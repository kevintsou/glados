# 節點卡

> **這份資料夾回答**：每個節點吃什麼、交什麼、怎樣算過、由誰做，以及目前打算怎麼實作。
>
> 每張卡分兩段：
>
> - **介面**：由框架固定，串接層照這一段開工、派工與收件。改這一段＝改框架。
> - **實作**：誰做、用什麼做。可以替換，之後一個節點一個節點展開。

## 節點卡的欄位

### 介面（框架固定）

| 欄位 | 寫什麼 |
| :---- | :---- |
| 目的 | 一句話說明這一站要完成什麼 |
| 層級 | 專案、模組或變更 |
| 由誰做 | 外部互動、派工或人 |
| 從哪裡進來 | 哪些情況會進到這個節點 |
| 輸入 | 要用到的產出物（名稱見 [產出物目錄](../framework/03_artifacts.md#31-產出物目錄)） |
| 輸出 | 要交出的產出物；每一站另外都要交交接說明（[03 §3.4](../framework/03_artifacts.md#34-交接說明)） |
| 擋關檢查 | 沒過就不能往下的檢查，意思見 [framework/05 §5.4](../framework/05_checks.md#54-擋關檢查) |
| 收件檢查 | 外部互動節點才有，見 [framework/05 §5.5](../framework/05_checks.md#55-收件檢查) |
| 出口關卡 | 需要哪個人工核准（[framework/02 §2.4](../framework/02_workflow.md#24-人工關卡)） |
| 失敗時 | 什麼情況回哪裡；沒寫的一律照 [framework/04 §4.5](../framework/04_rules.md#45-失敗處理) |
| 可寫範圍 | 可以寫哪些路徑、禁止碰哪些。寫成 `artifacts/…` 的路徑，都是指 `.glados/projects/<專案編號>/artifacts/…` |

派工節點的重做上限一律 3 輪，外部互動節點不設，不在各張卡重複。

### 實作（可替換，待展開）

| 欄位 | 寫什麼 |
| :---- | :---- |
| 執行者 | AI、工具、人，或組合 |
| 工具 | skill、MCP、測試框架、build 工具（總表見 [impl/tools.md](../impl/tools.md)） |
| 待展開議題 | 實作時要解決的問題 |
