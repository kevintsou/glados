# P4 整合

## 介面（框架固定）

- **目的**：把所有模組合在一起，驗證端到端的 boot flow。
- **層級**：專案
- **從哪裡進來**：所有模組都完成 M7。
- **輸入**：各模組的模組交接包（已通過且有效）、架構文件。
- **輸出**：
  - 整合 branch（commit SHA）。
  - boot flow 報告（`artifacts/integration/`）：綁定 image、測試集合與驗證環境的版本與 hash。
- **出口檢查**：模組交接齊全（所有模組）、build 零警告、記憶體在預算內、端到端 boot flow 通過、證據對應目前版本。
- **出口關卡**：無。
- **失敗退回**：交給 R 失敗分類：先找出對應的模組，再依問題類型退回該模組的某一站。
- **迴圈上限**：待定。
- **可寫範圍**：可寫整合 branch（只能合入各模組已通過的 commit）、`artifacts/integration/`。
- **人怎麼參與**：不參與。
- **獨立性要求**：無。

## 實作（待展開）

- **執行者**：工具＋AI。
- **執行方式**：純程式負責合入、build、跑測試；AI 判讀 log。
- **工具**：openBCT。
- **待展開議題**：
  - 合入的順序與衝突處理方式。
  - image 載入與跑測試的串接方式，和 M5 是同一個問題（見 [M5](M5.md)）。
